# 받은자료 웹 앱 (한 번만)

깃허브 페이지는 화면만 보여 줍니다. 제출된 주민등록번호·계좌·신분증·서명은
`내 드라이브 / 1.여행행사관련 / 5.spm(스마트파트너관리) / 받은자료`
폴더와 `받은자료_대장` 시트에만 저장합니다.

브라우저가 드라이브에 직접 쓰지 못하므로, 이재명 구글 계정으로 아래를 **처음 한 번** 하면 됩니다.

1. 크롬에서 https://script.google.com 을 엽니다.
2. 새 프로젝트를 누릅니다.
3. 기본 코드를 지우고, 이 폴더의 `Code.gs` (또는 드라이브의 `개인정보_드라이브저장.gs.txt`)를 모두 붙여 넣습니다.
4. 디스크 아이콘으로 저장합니다.
5. 오른쪽 위 **배포 → 새 배포**
6. 유형: **웹 앱**
7. 다음 계정으로 실행: **나**
8. 액세스 권한: **모든 사용자** (쓰기만 되고, 폴더는 비공개입니다)
9. 배포를 누르고, 허용이 나오면 허용합니다.
10. 나온 웹 앱 URL을 채팅에 보내 주세요. 비밀번호가 아닙니다.

연결되면 받는 분이 링크에서 제출할 때마다 `받은자료` 아래에
`날짜_지급건_성명` 폴더가 생기고, 인적정보 메모·신분증·서명이 들어갑니다.
