# SPM — 스마트파트너쉽관리

(주)투어메이커가 법인에서 돈을 지출할 때, **이체에 필요한 자료를 링크로 받고** 사업소득 원천 3.3%를 뺀 뒤 보내는 웹 앱입니다.

지금은 단순하게 시작합니다. 계약서·전자서명·객실배정은 지출 건에 묶지 않습니다.

## 이번 범위

- **김련 박사 강사료** (TM-260903, 태백해설사 심화교육 2026-09-03~04)
  - 투어메이커와 별도 계약 관계가 아닙니다. 수배 후 발주처(태백고생대자연사박물관) 견적 강사비 **2,000,000원**을 지출합니다.
  - 원천 3.3% 66,000원 → 이체 **1,934,000원**
  - 받는 정보: 이름, 주민등록번호, 신분증, 본인 명의 계좌
- 법인 지출 기본은 **사업소득 3.3%**. 직원 급여(근로소득)는 넣지 않습니다.
- 만족도 설문은 지출과 분리된 `/s/tm-260903` 입니다.
- 웹드라마 &lt;영서와 영동&gt; 자문은 **대표 개인 수입 참고**이며 법인 손금이 아닙니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:4721` 을 엽니다.

인적정보·신분증 사진·증빙 체크·새로 등록한 지출은 서버가 아니라 브라우저 `localStorage`에 남습니다.

## 원천 (현장 검토용)

실제 신고는 홈택스 숫자가 우선입니다.

| 유형 | 기본 처리 |
| --- | --- |
| 강사료 · 행사요원 · 용역 · 수익쉐어 | 사업소득 3.3% 원천 후 이체 |
| 체험비 | 개인 3.3% / 사업자면 세금계산서 |

## 저장소 이름

저장소 이름은 **spm** 입니다.
