# SPM — 스마트파트너쉽관리

(주)투어메이커가 법인 지출에 필요한 자료를 **링크로 받고**, 사업소득 원천 3.3%를 뺀 뒤 이체하는 웹 앱입니다.

카톡·구두·구글폼·외부 전자계약 대신, 투어메이커 자체 화면에서 성명·연락처·주민등록번호·신분증·본인 계좌·서명을 받아 기존 만족도 설문과 **같은 파이어베이스(`tourmaker-survey`)** 에 올립니다.

## 이번 범위

- **김련 박사 강사료** (TM-260903, 태백해설사 심화교육 2026-09-03~04)
  - 투어메이커와 별도 계약이 아닙니다. 발주처 견적 강사비 **2,000,000원**을 지출합니다.
  - 원천 3.3% 66,000원 → 이체 **1,934,000원**
  - 링크에서 제출 → `artifacts/tourmaker-survey-gform/public/data/responses_spm_{지출ID}`
- 직원 급여는 넣지 않습니다.
- 웹드라마 &lt;영서와 영동&gt; 자문은 대표 개인 수입 참고이며 법인 손금이 아닙니다.

미리보기(127.0.0.1)에서는 파이어베이스 도메인이 막혀 이 기기에만 남을 수 있습니다. 깃허브·투어메이커 배포 주소에서는 만족도 설문과 같이 연동됩니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:4721` 을 엽니다.

## 저장소 이름

저장소 이름은 **spm** 입니다.
