# SPM — 스마트파트너쉽관리

(주)투어메이커가 법인에서 돈을 지급할 때, 원천징수 후 이체하고 증빙을 한 묶음으로 남기는 웹 앱입니다.

지급 유형은 현장에서 반복되는 여섯 가지입니다.

- 인건비
- 행사요원
- 강사료
- 체험비
- 개인사업자 · 프리랜서
- 수익쉐어

각 건마다 설문(계좌·사업자 여부), 계약·전자서명 링크, 객실배정, 일정, 원천 계산, 증빙 체크를 붙입니다.

웹드라마 &lt;영서와 영동&gt; 자문 계약은 **대표 개인 기타소득 수입** 샘플입니다. 법인 손금과 섞지 않습니다. 계약서·촬영계획표·싸인오케이·설문을 한곳에 두는 형식을 보여 주기 위해 넣었습니다.

## 실행

```bash
npm install
npm run dev -- --port 4721 --hostname 0.0.0.0
```

브라우저에서 `http://localhost:4721` 을 엽니다.

설문 답, 객실배정, 증빙 체크, 새로 등록한 지급 건은 서버가 아니라 브라우저 `localStorage`에 남습니다. 주민등록번호 같은 원천 신고 항목을 넣더라도 외부로 전송하지 않습니다.

## 원천 계산 (안내)

실제 신고는 급여 프로그램·홈택스 숫자가 우선입니다. SPM은 현장 검토용입니다.

| 유형 | 기본 처리 |
| --- | --- |
| 인건비 | 근로소득. 간이세액·사대보험은 급여 원장 |
| 행사요원 | 일용근로. 1일 15만 원 공제 후 6.6% |
| 강사료 | 기타소득 필요경비 60%, 지급액의 8.8% |
| 체험비 | 사업자 세금계산서 / 미등록 3.3% |
| 개인사업자·프리랜서 | 세금계산서 또는 사업소득 3.3% (자문·강연이면 기타소득 8.8%) |
| 수익쉐어 | 정산서 + 세금계산서 또는 3.3% |

## 저장소 이름

저장소 이름은 **spm** (스마트파트너쉽관리) 입니다.
